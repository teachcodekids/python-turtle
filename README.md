# Python Turtle สำหรับ GitHub Pages

อัปโหลดไฟล์ `index.html`, `projects.js`, `studio.js`, `python-worker.js` และ `turtle_browser.py` จาก ZIP ไปยังโฟลเดอร์เดียวกับ `index.html` เดิมในแหล่งเผยแพร่ GitHub Pages แล้วกด **Commit changes** หาก GitHub Pages ตั้งค่าเป็น `/ (root)` ให้อัปโหลดที่ระดับแรกของ repository ถ้าตั้งเป็น `/docs` ให้อัปโหลดในโฟลเดอร์ `docs`

เมื่อเผยแพร่เสร็จ เปิดหน้าเว็บแล้วลองสร้างและบันทึกโปรเจกต์ จากนั้นกลับหน้าแรกหรือโหลดหน้าใหม่เพื่อเปิดงานเดิม

รุ่นนี้เก็บโปรเจกต์ใน localStorage โดยแยกตามเว็บไซต์และเบราว์เซอร์ ไม่มีระบบบัญชีหรือซิงก์ข้ามเครื่อง การล้างข้อมูลเว็บไซต์หรือใช้หน้าต่างส่วนตัวอาจทำให้เข้าถึงงานที่บันทึกไว้ไม่ได้ การรัน Python ต้องเชื่อมอินเทอร์เน็ตเพื่อโหลด Pyodide จาก CDN
