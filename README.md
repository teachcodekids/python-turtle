# Python Turtle

เว็บสำหรับฝึกเขียน Python Turtle ในเบราว์เซอร์ มีสีไวยากรณ์และเลขบรรทัด ตารางพิกัด x,y การวาดทีละขั้น การปรับความเร็ว และเมนูภาษาไทยกับอังกฤษ บัญชีที่เข้าสู่ระบบสามารถบันทึกและเปิดโปรเจกต์จากหน้าโปรเจกต์ของฉันได้

## อัปโหลดขึ้น GitHub

1. แตกไฟล์ ZIP แล้วเปิดโฟลเดอร์ที่แตกออกมา
2. สร้าง repository ใน GitHub แล้วอัปโหลดไฟล์และโฟลเดอร์ที่อยู่ข้างใน ZIP ให้ `README.md`, `web/`, `worker/` และ `drizzle/` อยู่ที่ระดับบนสุดของ repository
3. ตรวจว่าไฟล์ซ่อน `.gitignore` และ `.openai/hosting.json` ถูกอัปโหลดด้วย หากใช้งานผ่าน Git ในเครื่อง ใช้ `git add -A` เพื่อเพิ่มไฟล์เหล่านี้ได้

## โครงสร้างและการ build

| ตำแหน่ง | หน้าที่ |
| --- | --- |
| `web/` | หน้าโปรเจกต์ ตัวแก้ไข Python และพื้นที่วาด Turtle |
| `worker/server.js` | ให้บริการเว็บและ API สำหรับบันทึกและเปิดโปรเจกต์ตามเจ้าของบัญชี |
| `worker/build.mjs` | รวมหน้าเว็บและ Worker เป็นไฟล์สำหรับ deploy |
| `drizzle/` | SQL migration สำหรับสร้างตารางโปรเจกต์ |
| `.openai/hosting.json` | การตั้งค่า Sites ของโปรเจกต์ต้นฉบับ |

ใช้ Node.js 22 ขึ้นไปและรันจากโฟลเดอร์หลักของ repository

```sh
node worker/build.mjs
node --check dist/server/index.js
```

ผลลัพธ์คือ `dist/server/index.js` ซึ่งเป็น Cloudflare Worker ไม่ต้องติดตั้งแพ็กเกจ npm เพื่อ build

## โฮสต์เว็บและระบบบัญชี

ซอร์สชุดนี้ใช้ **ChatGPT Sites** สำหรับการเข้าสู่ระบบ และใช้ **Cloudflare D1** ผ่าน binding ชื่อ `DB` สำหรับเก็บโปรเจกต์ แพลตฟอร์มโฮสต์เป็นผู้จัดการการเข้าสู่ระบบและส่งตัวระบุบัญชีที่ยืนยันแล้วให้ Worker หากนำไปโฮสต์บนแพลตฟอร์มอื่น ต้องเชื่อมระบบยืนยันตัวตนที่เชื่อถือได้และตั้งค่า D1 พร้อมใช้ migration ก่อนเปิดระบบโปรเจกต์

GitHub ใช้เก็บซอร์สชุดนี้ได้ ส่วน **GitHub Pages** ให้บริการไฟล์สแตติก จึงรัน Worker, API, การเข้าสู่ระบบ และฐานข้อมูลของเว็บรุ่นนี้ไม่ได้ด้วยตัวเอง

หาก deploy เป็น Sites ใหม่ ให้ใช้ project ID ของ Sites ใหม่นั้นแทน ID ของเว็บต้นฉบับใน `.openai/hosting.json` การอัปโหลดเข้า GitHub ไม่ย้ายโปรเจกต์ที่ผู้ใช้บันทึกไว้ในฐานข้อมูล

Python รันในเบราว์เซอร์ผ่าน Pyodide ซึ่งโหลดจาก CDN เมื่อรันครั้งแรก
